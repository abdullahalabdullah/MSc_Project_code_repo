# Project notes for Claude

## Documentation
- **After any major code change, update `documentation.md`.** Treat the docs as part
  of the change, not a follow-up: when you add/remove/rename scripts, change the
  pipeline flow, move folders, alter config keys/paths, or change how something is
  computed or reported, update the relevant `documentation.md` sections in the same
  pass. Don't leave the docs describing removed scripts, old paths, or stale behavior.
