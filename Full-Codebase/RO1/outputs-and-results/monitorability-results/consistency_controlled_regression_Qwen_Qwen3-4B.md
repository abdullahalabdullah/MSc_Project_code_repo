# Consistency effect on monitorability, with controls — Qwen_Qwen3-4B

OLS of per-question g-mean² on `consistent` (same answer in all valid unhinted runs) plus controls. Coefficient = difference in g-mean² between consistent and inconsistent questions holding the controls fixed. 95% CI from a cluster bootstrap over questions (2000 resamples). Generated by `scripts/55_consistency_controlled.py`.

Rows: 2750 question × hint slices (1383 questions; 1317 consistent, 1433 inconsistent).

| Model | Consistency effect | 95% CI |
|---|---:|---|
| (1) consistent only | +0.121 | [+0.092, +0.151] |
| (2) + dataset + hint type | +0.089 | [+0.061, +0.117] |
| (3) + log unhinted length | +0.081 | [+0.050, +0.112] |
| (4) + p0 > 0 | +0.044 | [+0.010, +0.077] |

Controls: dataset and hint type as fixed effects; length = log(mean unhinted CoT tokens); p0 > 0 = the model picks the hint target in at least one unhinted run (occurs only among inconsistent questions). TPR_mc already corrects for p0 via R_effect, so (4) is a bound on how much of the effect could be tied to that correction, not a correction the metric is missing.
