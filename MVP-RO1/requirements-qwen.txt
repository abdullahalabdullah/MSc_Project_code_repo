# =============================================================================
# Qwen3 (thinking-model) environment for MVP-RO1.
#
# The pinned stack in requirements.txt (torch 2.4 / transformers 4.46.3 /
# vLLM 0.6.3) predates Qwen3 and fails with:
#   ValueError: ... model type `qwen3` but Transformers does not recognize ...
#
# Qwen3 (model_type "qwen3") requires transformers >= 4.51.0 and vLLM >= 0.8.5,
# which in turn require torch >= 2.6. That whole stack is INCOMPATIBLE with the
# Llama/Tulu pins, so install this in a SEPARATE virtualenv:
#
#   python -m venv ~/qwen_env
#   source ~/qwen_env/bin/activate
#   pip install -r requirements-qwen.txt
#   python -c "import vllm, transformers; print(vllm.__version__, transformers.__version__)"
#
# Then run inference with the Qwen scripts:
#   python scripts/02_run_inference_qwen.py --model qwen3_4b
#
# Only scripts 02_run_inference_qwen.py and 07_estimate_accuracy_qwen.py need
# this env (they load the model). Steps 03-06 are model-agnostic and run under
# either environment.
# =============================================================================
