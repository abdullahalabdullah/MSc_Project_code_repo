# MVP-RO1 environment — shared by BOTH eval suites (monitorability-eval/ and
# harmlessness-eval/). The harmlessness eval adds no new dependencies: WildGuard
# (Mistral-7B) is served by the same vLLM pin below and WildJailbreak loads via
# `datasets`; huggingface_hub (used by ensure_hf_auth) comes in transitively.
#
# Qwen3 (thinking-model) evaluation pipeline.
#
# Qwen3 (model_type "qwen3") requires transformers >= 4.51.0 and vLLM >= 0.8.5,
# which in turn require torch >= 2.6. Install into a FRESH virtualenv (needs
# ~8-10 GB free for the torch+CUDA stack):
#
#   python -m venv ~/qwen_env
#   source ~/qwen_env/bin/activate
#   pip install -r requirements.txt
#   python -c "import vllm, transformers; print(vllm.__version__, transformers.__version__)"
#
# Then run inference:
#   python scripts/02_run_inference_qwen.py --model qwen3_1_7b
#
# Only scripts/02_run_inference_qwen.py loads the model (needs vLLM/torch);
# steps 03-06 are model-agnostic analysis and run anywhere.
#
# -----------------------------------------------------------------------------
# IMPORTANT — versions are PINNED EXACTLY, not floored. An unbounded floor
# (vllm>=0.8.5) lets the resolver pull the newest wheels, which broke on a
# CUDA-12.8 machine (driver 570.x). The failures, in order, were:
#
#   1. vLLM 0.23.0 bundled a torch built for CUDA 12.9+  ->
#        RuntimeError: The NVIDIA driver on your system is too old (12080)
#   2. A leftover too-new transformers dropped a tokenizer attribute vLLM uses ->
#        AttributeError: Qwen2Tokenizer has no attribute all_special_tokens_extended
#   3. A leftover flashinfer/.so built against a different torch ABI ->
#        OSError: undefined symbol _ZNK3c106Device3str... (c10::Device::str)
#
# The combination below is the known-good pairing for a CUDA-12.8 driver:
#   vLLM 0.8.5  ->  torch 2.6.0 (cu124, runs on a 12.8 driver)
#   transformers 4.51.3  (matches vLLM 0.8.5's tokenizer API; supports qwen3)
#
# Do NOT install flashinfer in this env. vLLM 0.8.5 does not need it (it falls
# back to the torch-native top-k/top-p sampler). If a previous install left it
# behind, remove it before running:
#   pip uninstall -y flashinfer flashinfer-python tvm-ffi tvm_ffi torch_c_dlpack_ext
#
# Always install into a FRESH venv. Downgrading an existing newer-vLLM env in
# place leaves mismatched leftovers (torch/transformers/flashinfer) that surface
# one error at a time. A fresh venv needs ~8-10 GB free for the torch+CUDA stack.
# =============================================================================
